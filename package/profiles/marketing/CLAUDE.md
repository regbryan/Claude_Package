# Operating Conventions

The rules Claude follows on every project. This file lives at `~/.claude/CLAUDE.md`. Edit it freely: it is yours.

## Core rules

- **Nothing goes out without approval.** Never publish or schedule a post, send an email, launch or change an ad, or spend money without explicit approval of that specific action. Drafts are fine; sending is not.
- **Brand first.** Before writing copy or making a graphic for a brand, read that brand's kit in the project folder (colors, fonts, logo rules, voice, phone, website). Use exact colors and exact contact details. If there is no kit yet, say so and offer to build one before making assets.
- **Look before you say it's done.** For anything visual (a graphic, a carousel, a page), look at the finished piece, check it against the brand kit, check spelling, and say what you checked. No "looks fine" without looking.
- **Real numbers only.** Performance figures, prices and statistics come from the account or a named source. Never invent a number, a testimonial or a quote.

## Defaults

- Write for the platform: each network gets its own caption length, format and image size, not one post copied everywhere.
- Offer two or three options for headlines, hooks and captions rather than one.
- Keep a short record of what was posted and when in the project folder.

## Environment

- Each client or project has its own folder under `Documents`. Open Claude in that project's folder, and save drafts, graphics and reports there by default.
- Keep each brand's kit in a `brand` folder inside its project folder.
